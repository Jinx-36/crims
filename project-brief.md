# CrimsAI Website - Project Brief

## Overview
Build a frontend-only brochure website for CrimsAI using Next.js and Framer Motion. There is no backend or database integration for this phase. The design must be clean, highly structured, and feature smooth, impressive animations throughout.

## Core Directives for Agy
1. **Mandatory Skill Usage:** 
   - Every time you modify or create UI components, you MUST invoke the `.agents/skills/design-taste-frontend` and `.agents/skills/stitch-design-taste` skills to ensure aesthetic quality.
   - For any interactive or animated elements, you MUST invoke the `.agents/skills/framer-motion-animator` skill.
2. **Content Source of Truth:** Use the exact text provided in `artifacts/CRIMSAI — WEBSITE COPY.pdf`. Do not alter the copy; it is already optimized to be direct and free of unnecessary corporate metaphors.
3. **Component Structure:** Break down the UI into modular, reusable React components (e.g., `<Hero />`, `<ServiceCard />`, `<FAQAccordion />`).
4. **Styling:** Use Tailwind CSS for layout and styling, combined with Framer Motion for all animations.

## Image Generation (Stitch MCP)
When generating placeholder or supporting illustrations using Stitch:
- **Visual Anchor:** All generated assets must match the exact visual style, elegance, and color palette of `artifacts/logo-crims-bm1.jpg` (minimalist line art, deep burgundy/red accents, cream/off-white backgrounds).
- **Subject Matter:** Keep illustrations abstract, professional, and tied to the beauty/growth niche without being overly literal.
